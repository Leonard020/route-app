## 아직 안 한 것 (로그에 남김)

- 실제 노선 그래프 (`GraphProvider.neighbors` 비어 있음). 후보는 가까운 버스/지하철 지점 휴리스틱.
- 지도 SDK (상세는 개략도).
- 길안내 GPS tick·재탐색 동의·푸시 (세션 시작/종료 UI만).
- 설정값 서버 `PATCH /settings` (로그인 필요) — 프론트는 localStorage.
- 최근검색 서버 API — 프론트는 localStorage.
- 두 통계 데이터 적재 및 표준정류장ID·역사ID 매핑.
- 이미 떠 있는 DB에는 `docker/postgres/06_demand.sql` 수동 실행 필요 (볼륨이 있으면 init 스크립트가 다시 안 돌아감).
- `_spec_dump.txt` 는 커밋하지 않음.
